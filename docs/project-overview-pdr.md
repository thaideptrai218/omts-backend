# Project overview and requirements

Updated: 2026-10-05.

OMTS Backend provides an ASP.NET Core foundation and repository governance for a future OMTS backend. Deliverables: a public GitHub repository, executable operational API, deterministic dependency management, tests, container packaging, CI, container publication and contribution standards. The owner explicitly selected public visibility to enable branch protection on the current GitHub plan.

Acceptance: locked dependency restore, strict Release build, integration tests and formatting pass; GitHub CI builds and exercises a real container; repository settings and unsupported controls are recorded accurately. No committed credentials or external deployment side effects.

Business capabilities, user roles, data model, database, identity provider, traffic targets, compliance requirements and hosting environment have not been supplied. These requirements must be specified before product implementation and production approval.
