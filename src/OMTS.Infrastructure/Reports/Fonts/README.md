# Report fonts

`NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` (Noto Sans, hinted, from https://github.com/notofonts/notofonts.github.io) are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). They are embedded in the Infrastructure assembly and registered by `ReportDocumentPdfRenderer` so the PDF reports render Vietnamese diacritics without any font installed on the machine.
